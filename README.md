# Lat's Collections – Boutique Website

A responsive website for my family's boutique, Lat's Collections,
selling Baju Melayu, corporate wear and accessories in Kuala Lumpur.

## Features
- Responsive design (desktop, tablet, mobile)
- Mobile hamburger menu built with JavaScript
- Product cards with "Order via WhatsApp" buttons
- Smooth scrolling navigation

## Built With
- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, event listeners)
